# APIVaultPro

APIVaultPro enables secure, real-time data encryption and auto-scaling through a scalable API gateway and load balancing broker.

The key benefits of using APIVaultPro include:

- APIVaultPro enables secure, real-time data
- encryption and auto-scaling through a
- scalable API gateway and load

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/APIVaultPro.git`
2. `cd APIVaultPro`
3. Install in editable mode: `pip install -e .`

## Configuration

APIVaultPro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
